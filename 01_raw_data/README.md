# 01_raw_data  (not included in this repository)

The raw single-cell data are not redistributed here. They are the original
10x Genomics count matrices from the three source studies, available from GEO:

- GSE227190
- GSE159032
- GSE262689

Download the per-sample matrices from GEO and place them here to run the
integration pipeline in `02_code/01_integration/`.
