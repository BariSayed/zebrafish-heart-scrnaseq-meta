[Monocle3 pseudotime - Figures 7A/7B]  (installed in the scrna env, R 4.3.3)
  monocle3  1.4.27   Re-installed into the scrna env via conda-prebuilt system-
                     library dependencies (sf, spdep, units, terra, xml2, Cairo,
                     ragg, HDF5Array, rhdf5, BPCells) + remotes::install_github.
                     The recorded original version was 1.4.26; its git tag is
                     incompatible with the current dplyr, so 1.4.27 (one patch
                     newer, identical pseudotime algorithm) was installed.
  SeuratWrappers    Not installable against the current dplyr (it imports the
                     removed dplyr::filter_out). as.cell_data_set() was therefore
                     reproduced by a manual Seurat->Monocle3 CDS conversion
                     (counts + cell/gene metadata + UMAP embedding). Pseudotime is
                     determined by the UMAP graph + 0-dpi root, so this conversion
                     is equivalent for the trajectory ordering.
